## Overview
Data Security Concepts course assignment from T.A. Marryshow Community College. Practical analysis of phishing emails, identification of red flags, and creation of security awareness content.

## Key Learning Points
### Phishing Red Flags
- Suspicious sender addresses
- Urgent or threatening language
- Mismatched URLs and links
- Request for sensitive information
- Poor grammar and spelling

### Safe Email Rewriting
- Transforming phishing emails into educational content
- Highlighting security best practices
- Creating user-friendly security warnings

### Security Awareness Training
- Developing user education materials
- Demonstrating real-world phishing examples
- Teaching email verification techniques
